# Second Brain OS V100 · VISUAL & DATA CORE

Первый контролируемый этап полной визуальной и технической стабилизации.

- Исправлены карточки «Мои папки»: фиксированная зона иконки, читаемая типографика, устойчивые суммы, адаптивная сетка.
- Иконки папок исключены из повторной SVG-декорации.
- Менеджер финансовых категорий приведён к одной финальной реализации и полноширинной компоновке.
- Кнопки категорий перенесены под содержание; шрифты и области нажатия увеличены.
- Добавлен канонический расчёт актуального остатка долга: currentBalance → компоненты долга → legacy amount минус платежи.
- Суммы обязательств на главной и в детализации используют актуальный остаток.
- Версии HTML, runtime, manifest и Service Worker согласованы на V100.

Ключ secondBrainOS.v1 не менялся. Очистка localStorage и IndexedDB не добавлялась.

# Публикация Second Brain OS V101

1. Распакуйте `second-brain-oc-v101-upload-files.zip`.
2. Загрузите все файлы из архива в корень ветки GitHub Pages с заменой.
3. Обязательно проверьте, что в корне появились `version-v101.js`, `recover-v101.html`, обновлённые `sw.js`, `index.html` и `app-v93-assistant.js`.
4. Дождитесь завершения GitHub Pages.
5. Откройте:
   `https://en6dea.github.io/second-brain-oc/recover-v101.html`
6. Запустите обновление интерфейса. Страница удаляет только UI-кэш приложения и не очищает пользовательские данные.
7. Затем откройте:
   `https://en6dea.github.io/second-brain-oc/?v=101#today`
8. Внизу должна отображаться метка `V101 · UI TRUTH FIX`.

Ручная проверка после публикации:
- пустая очередь «Разобрать» показывает «Очередь полностью разобрана»;
- в «Операциях» не показывается ложное требование категорий;
- «Посмотреть день» открывает дневной вид календаря;
- в категории доступны разные иконки;
- вся строка финансового чек-листа кликабельна.

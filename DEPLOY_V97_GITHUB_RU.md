# Публикация Second Brain OS V97 в GitHub Pages

1. Распакуйте `second-brain-oc-v97-upload-files.zip`.
2. Загрузите **все файлы из архива в корень** репозитория с заменой. Папки для обязательных файлов больше не требуются.
3. Дождитесь завершения GitHub Pages.
4. Откройте `https://en6dea.github.io/second-brain-oc/?v=97#today`.
5. В настройках откройте блок «Версия, файлы и сохранность» и нажмите «Проверить файлы».
6. Если остаётся старая версия, нажмите «Обновить интерфейс без удаления данных». Очищается только кэш `second-brain-os-*`; записи не удаляются.
7. В интерфейсе должна отображаться метка `V97 · PUBLISH & VISUAL`.

Перед публикацией можно запустить: `node qa-v97-predeploy.js`.

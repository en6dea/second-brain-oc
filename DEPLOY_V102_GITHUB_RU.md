# Публикация Second Brain OS V102

1. Скачайте архив `second-brain-oc-v102-upload-files.zip`.
2. Распакуйте его.
3. Загрузите всё содержимое в корень репозитория `en6dea/second-brain-oc` с заменой файлов.
4. Проверьте наличие в корне:
   - `version-v102.js`
   - `styles-v102-product.css`
   - `app-v102-product.js`
   - `recover-v102.html`
   - обновлённых `index.html`, `sw.js`, `manifest.webmanifest`, `app-v93-assistant.js`.
5. Дождитесь завершения GitHub Pages.
6. Откройте `https://en6dea.github.io/second-brain-oc/recover-v102.html`.
7. Нажмите «Восстановить загрузку приложения». Удаляется только интерфейсный кэш Second Brain OS; пользовательские данные не очищаются.
8. Откройте `https://en6dea.github.io/second-brain-oc/?v=102#today`.
9. Внизу должна отображаться версия `V102 · VISUAL GUIDANCE`.

## Обязательный ручной прогон

- Главная: папки, суммы, иконки и быстрые привычки.
- Привычки: 0/4, цветные иконки, отметка привычки.
- Финансы → Аналитика: пояснения `?`, график категорий, отсутствие белых полос.
- Финансы → Планирование: предупреждения помощника должны быть сверху.
- Календарь: «Посмотреть день» открывает дневной режим.
- Информация → Заметки / Идеи / Путешествия: кнопки помощника выполняют полезное действие.
- Путешествия: запись без фото получает фирменную заглушку и кнопку добавления обложки.
- Состояние Полины: все даты имеют одинаковые размеры.

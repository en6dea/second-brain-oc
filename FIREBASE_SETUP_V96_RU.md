# Настройка Firebase для V96

Облачная синхронизация является опциональной. Без настройки приложение продолжает работать локально и не запрашивает email или пароль.

## Порядок

1. Создайте отдельный Firebase project.
2. В Authentication включите Email/Password.
3. Создайте Firestore Database.
4. Скопируйте web app config в `firebase-config.js`, не меняя имя `window.SECOND_BRAIN_FIREBASE_CONFIG`.
5. Разверните правила из `firestore.rules`.
6. Проверьте вход и синхронизацию сначала на тестовой базе.

Команда для правил при установленном Firebase CLI:

```bash
firebase deploy --only firestore:rules
```

## Модель хранения

Данные пользователя сохраняются по пути:

`users/{uid}/state/main`

Правила разрешают доступ только пользователю, чей UID совпадает с `{uid}`.

## Важное ограничение

V96 использует ручные действия «Отправить данные» и «Загрузить из облака». Это намеренно: автоматическое слияние двух финансовых баз без отдельного conflict resolver небезопасно.

# Публикация Second Brain OS V103

1. Скачайте `second-brain-oc-v103-upload-files.zip`.
2. Распакуйте архив.
3. Загрузите всё содержимое в корень репозитория `en6dea/second-brain-oc` с заменой одноимённых файлов.
4. Дождитесь завершения GitHub Pages.
5. Откройте `https://en6dea.github.io/second-brain-oc/recover-v103.html`.
6. Нажмите «Восстановить загрузку приложения». Удаляется только UI-кэш; записи и настройки остаются.
7. Откройте `https://en6dea.github.io/second-brain-oc/?v=103#today`.
8. Версию проверяйте в разделе «Настройки». На главной бейдж версии намеренно скрыт.

## Быстрая ручная проверка

- На главной карточки не пересекаются, два верхних блока одной высоты, нижние ряды выровнены.
- В GameLife-плашке отображается фотография профиля, если она задана.
- В «Движение денег» пять KPI имеют центрированную кнопку «Что это».
- Блок «Расходы по категориям» содержит график и AI-разбор по клику на категорию.
- При переходах между разделами фирменная сфера не должна визуально начинать вращение с нуля.
- В «Настройки» отображается `V103 · PERFECT ALIGNMENT`.

Старые файлы `app-v102-product.js`, `styles-v102-product.css`, `version-v102.js` и `recover-v102.html` больше не подключаются. Их можно удалить из репозитория после успешной проверки V103.

# Second Brain OS V98 · LOAD RECOVERY

## Причина зависания V97
В `version-v97.js` MutationObserver следил за всем DOM и при каждом изменении повторно присваивал `textContent` бейджу версии. Само присваивание создавало новое DOM-изменение, что запускало observer снова. В результате браузер попадал в цикл мутаций и страница могла зависать до завершения загрузки.

## Исправление
- новый безопасный `version-v98.js` обновляет только реально изменившиеся узлы;
- observer обрабатывает только добавленные элементы и не пишет одинаковое значение повторно;
- все новые ресурсы получили новые имена/версии для обхода старого HTTP/PWA-кэша;
- добавлена отдельная страница `recover-v98.html`, удаляющая только UI-кэш и регистрацию Service Worker;
- пользовательский ключ `secondBrainOS.v1` и IndexedDB приложения не очищаются.

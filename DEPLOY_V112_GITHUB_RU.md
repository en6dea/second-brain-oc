# Публикация Second Brain OS V112 на GitHub Pages

1. Распакуйте GitHub-ready архив.
2. Загрузите **содержимое папки `second-brain-oc-main`** в корень репозитория с заменой файлов.
3. Дождитесь завершения GitHub Pages deployment.
4. Откройте:

```text
https://en6dea.github.io/second-brain-oc/recover-v112.html
```

5. Нажмите «Обновить интерфейс».
6. После восстановления откройте:

```text
https://en6dea.github.io/second-brain-oc/?v=112-r1#couple-random
```

## Что делает recovery

Recovery удаляет только старые Service Worker и UI-кэши. Пользовательские данные, `localStorage`, IndexedDB, финансы, цели, привычки и записи не очищаются.

## Проверка версии

В настройках должна отображаться версия:

```text
V112 · PAIR RANDOM MONTH
```

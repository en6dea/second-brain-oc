# Публикация Second Brain OS V100

1. Скачайте архив `second-brain-oc-v100-upload-files.zip`.
2. Распакуйте его.
3. Загрузите все файлы из архива в корень репозитория `en6dea/second-brain-oc` с заменой существующих.
4. Дождитесь завершения GitHub Pages.
5. Откройте:

`https://en6dea.github.io/second-brain-oc/?v=100#today`

В интерфейсе должна отображаться метка `V100 · VISUAL & DATA CORE`.

Если браузер продолжает показывать старую версию, откройте:

`https://en6dea.github.io/second-brain-oc/recover-v100.html`

Страница восстановления удаляет только кэш интерфейса и регистрацию Service Worker этого приложения. `localStorage`, IndexedDB и ключ `secondBrainOS.v1` не очищаются.

## Быстрая ручная проверка

- На главной иконки папок не перекрывают текст.
- Сумма `269 100 ₽` или другая длинная сумма остаётся в одной строке внутри плашки.
- В `Финансы → Категории и лимиты` карточки расходов и доходов читаются без переноса по буквам.
- Кнопки `Настроить`, `Скрыть`, `В архив` находятся под текстом категории.
- Сумма обязательств соответствует текущим остаткам долгов.

# Как откатить оформление

Дизайн Lumen (V114) добавлен так, чтобы его можно было снять в любой момент.
Способы идут от самого быстрого к самому основательному. Ваши данные не
затрагиваются ни одним из них — см. раздел «Данные» внизу.

## Способ 1. Снять только новый слой (10 секунд)

В `index.html` замените две строки:

```html
<link rel="stylesheet" href="styles-dark-base.css?v=v114-r3">
<link rel="stylesheet" href="styles-lumen.css?v=v114-r3">
```

на одну исходную:

```html
<link rel="stylesheet" href="styles.css?v=v114-r3">
```

Файл `styles.css` — оригинальная светлая таблица стилей, она никуда не
удалялась и не изменялась. Приложение вернётся к прежнему виду.

Осталась одна деталь: тема жёстко переведена в тёмную в двух местах —
`version.js` (функция `apply`) и `app.js` (около строки 2495, `const dark=true`).
Для полного возврата к светлой теме верните там `light` / расчёт по настройке ОС.

## Способ 2. Вернуть весь коммит с оформлением

```bash
git revert --no-commit $(git rev-parse HEAD) && git commit -m "Revert Lumen redesign"
```

## Способ 3. Вернуться к проверенному состоянию до редизайна

Есть метка и ветка, указывающие на состояние, проверенное в браузере:

```bash
git checkout stable/v113-consolidated
```

Ветка с тем же состоянием — `backup/pre-lumen`. Вернуть в неё основную работу:

```bash
git reset --hard stable/v113-consolidated
```

Команда `reset --hard` уничтожает незакоммиченные правки — сохраните их
заранее через `git stash -u`.

## Что именно изменено в V114

| Файл | Что с ним |
|---|---|
| `styles.css` | **не изменялся** — исходная светлая таблица, точка отката |
| `styles-dark-base.css` | новый: тот же `styles.css`, но цвета переведены в токены |
| `styles-lumen.css` | новый: токены и переработанный визуальный слой |
| `index.html` | подключение стилей, цвет темы, версии файлов |
| `version.js` | версия V114, тёмная тема |
| `app.js` | только выбор темы (около строки 2495), логика не тронута |
| `sw.js`, `manifest.webmanifest` | версия кэша и цвета |

## Как пересобрать тёмную основу

`styles-dark-base.css` собирается скриптом из `styles.css`. Правки вносите
в `styles.css` и пересоберите, иначе они потеряются:

```bash
powershell -File scripts/recolor.ps1
```

Скрипт разбирает объявления по свойствам и переводит цвета в токены по
светлоте и оттенку: тёмный текст → `--lm-ink`, светлые фоны → `--lm-surface`,
насыщенные цвета → семантические токены. Пользовательские свойства (`--v78-*`
и прочие) он не трогает — они переопределены мостом в `styles-lumen.css`.

## Данные

Ни один из способов отката не затрагивает ваши записи. Полное состояние
хранится в IndexedDB (база `SecondBrainOSDurableStorage`, ключ `main-state`),
в `localStorage` лежит компактное зеркало — так устроено с версии 104.
Оформление к хранилищу не имеет отношения, схема данных (`dataSchemaVersion: 3`)
в V114 не менялась. Приложение дополнительно создаёт резервную копию при
переходе на новую версию (ключи вида `secondBrainOS.v114.backupCreated`).

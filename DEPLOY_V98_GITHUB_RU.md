# Публикация V98

1. Распакуйте архив `second-brain-oc-v98-upload-files.zip`.
2. Загрузите всё содержимое в корень ветки `main` с заменой.
3. Дождитесь завершения GitHub Pages.
4. Сначала откройте `https://en6dea.github.io/second-brain-oc/recover-v98.html`.
5. Нажмите «Восстановить загрузку приложения».
6. После перехода должна открыться `?v=98#today` и метка `V98 · LOAD RECOVERY`.

Страница восстановления удаляет только кэши с префиксом `second-brain-os-` и регистрации Service Worker. Пользовательские записи не удаляются.

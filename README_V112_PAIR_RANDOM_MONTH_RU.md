# Second Brain OS V112 — «Парный рандом месяца»

В актуальную сборку встроен новый раздел для Алексея и Полины: один месяц — один новый совместный опыт.

## Реализовано

- живая круглая рулетка с плавным вращением и фиксацией результата до начала анимации;
- уровни сложности: простой, средний, сложный и полный рандом;
- локальная база из 1 000 заданий в 40 категориях;
- умная фильтрация по бюджету, сложности, сезону, месту, режиму и ранее выполненным заданиям;
- распределение равнозначных ролей Алексея и Полины;
- ограничение замен и обязательная фиксация причины отказа;
- автоматический план на четыре недели;
- отдельный прогресс каждого участника и общий прогресс;
- бюджет, расходы и необязательная связь с финансовыми операциями;
- выводы Алексея, Полины и общий вывод пары;
- прикрепление фото, видео, аудио, документов и ссылок;
- завершение месяца с оценками, результатами и памятной фразой;
- автоматическое создание воспоминания в «Личной памяти»;
- история завершённых месяцев;
- архив всех запусков, результатов, отказов и замен;
- добавление собственных заданий;
- создание, редактирование, отключение и архивирование собственных категорий;
- мягкий ежемесячный ритуал, еженедельный чек-ин и минимальный первый шаг;
- отсутствие давления, чувства вины и обнуления прогресса после паузы.

## Хранение данных

Модуль использует существующий объект состояния Second Brain OS и хранится в:

```js
state.coupleRandom
```

Основной ключ приложения не меняется. `localStorage`, IndexedDB и существующие записи не очищаются.

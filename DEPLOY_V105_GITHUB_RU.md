# Публикация V105

1. Распакуйте архив `second-brain-oc-v105-upload-files.zip`.
2. Загрузите файлы в корень репозитория с заменой.
3. Откройте `/recover-v105.html` и нажмите восстановление интерфейса.
4. Затем откройте `/?v=105#gamelife`.
5. В GameLife не должно быть сообщения `hpJournal is not defined`.

Recovery удаляет только кэши интерфейса и регистрацию Service Worker. `localStorage`, IndexedDB и `secondBrainOS.v1` не очищаются.

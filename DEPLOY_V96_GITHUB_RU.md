# Публикация Second Brain OS V96 в GitHub Pages

## Перед загрузкой

1. В текущем приложении откройте «Настройки».
2. Скачайте JSON-резервную копию.
3. Сохраните V95 ZIP для отката.

## Загрузка

1. Распакуйте `second-brain-oc-v96-upload-files.zip`.
2. Загрузите всё содержимое в корень `en6dea/second-brain-oc`.
3. Подтвердите замену файлов и сохранение вложенных папок `src/app`, `src/storage`, `src/styles`.
4. Дождитесь завершения GitHub Pages deployment.

## Проверка

Откройте:

`https://en6dea.github.io/second-brain-oc/?v=96#today`

Проверьте:

- внизу указано `V96 · STABLE CORE`;
- основные разделы и данные на месте;
- в «Настройки» появился блок «Стабильность и сохранность»;
- backup V96 имеет дату;
- при пустом `firebase-config.js` написано «Синхронизация не настроена» и нет полей пароля;
- «Финансы → Операции → Импорт CSV» открывается;
- после перезагрузки записи остаются.

## Если показывается старая версия

Используйте кнопку «Настройки → Обновить интерфейс → Очистить кэш». Она удаляет только PWA-кэши Second Brain OS и не удаляет личные данные.

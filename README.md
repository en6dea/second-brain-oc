# Second Brain OS

Личная операционная система для повседневной жизни: сегодняшний фокус, привычки, календарь, финансы, обязательства (долги) и личная информация — в одном PWA-приложении без сервера.

## Структура

Статическое приложение, без сборки и зависимостей:

- `index.html` — разметка и точки входа.
- `app.js` — вся логика интерфейса и маршрутов (single bundle).
- `app-cloud.js` — необязательная синхронизация через Firebase, резервные копии и PWA-обновления (загружается через `defer`).
- `styles-dark-base.css` — рабочая таблица стилей: это `styles.css` с цветами, переведёнными в токены Lumen. Собирается скриптом `scripts/recolor.ps1`.
- `styles-lumen.css` — дизайн-система Lumen: токены, мост к переменным прошлых версий, переработанный визуальный слой.
- `styles.css` — исходная светлая таблица стилей. Не подключена; хранится как точка отката и как источник для пересборки (см. [ROLLBACK.md](ROLLBACK.md)).
- `version.js` — метаданные сборки, используются также сервис-воркером.
- `sw.js` — офлайн-кэш (service worker).
- `manifest.webmanifest`, `offline.html`, `force-update.html`, `icon-*.png` — PWA-обвязка.
- `firebase.json`, `firestore.rules`, `storage.rules`, `.firebaserc.example` — шаблон для опциональной облачной синхронизации.

Раньше эти файлы существовали десятками версий (`app-v91.js`, `app-v93.js`, ... `styles-v112.css` и т.д.), подключённых в index.html одновременно. Всё это склеено в единые `app.js`/`styles.css` без изменения поведения; старые версии остались в истории git.

## Оформление

Визуальная система — **Lumen** (тёмная): один набор токенов вместо прежних 179 переменных в 11 конкурирующих блоках `:root`. Смена палитры — правка токенов в начале `styles-lumen.css`.

Откат оформления и пересборка тёмной основы описаны в [ROLLBACK.md](ROLLBACK.md).

## Запуск локально

```bash
python -m http.server 8834
```

Откройте `http://localhost:8834`. Данные хранятся в браузере (`localStorage`), синхронизация с облаком отключена, пока не заполнен `firebase-config` в приватном окружении.

## Облачная синхронизация (опционально)

1. Скопируйте `firebase-config.example.js` → `firebase-config.js` и подставьте реальные ключи Firebase Web SDK. Файл в `.gitignore` — в репозиторий не попадёт.
2. Скопируйте `.firebaserc.example` → `.firebaserc` с реальным ID проекта (тоже в `.gitignore`).
3. Разверните `firestore.rules` и `storage.rules`.

Без этого шага приложение работает полностью локально.
